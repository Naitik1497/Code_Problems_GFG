<h2><a href="https://www.geeksforgeeks.org/problems/student-of-the-year/1">Sort According to Criteria</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">Given an array of Student objects, where each object contains the student's name (in lowercase letters) and <strong>marks</strong> obtained in an exam, </span></p><ul><li><span style="font-size: 18px;">Sort the array in descending order of marks. </span></li><li><span style="font-size: 18px;">If two or more students have the same marks, sort them in lexicographical order of their names.</span></li></ul><p><span style="font-size: 18px;"><strong>Examples: </strong></span></p><pre><span style="font-size: 18px;"><strong>Input: </strong>arr[] = [{michal 56}, {john 100}, {abbas 98}, {jordan 45}]
<strong>Output: </strong>[{john 100}, {abbas 98}, {michal 56}, { jordan 45}]

Among students scoring 90, rahul comes before zara. Hence the sorted order is:
aman 95, bhavesh 95, rahul 90, zara 90.</span></span></pre><p><span style="font-size: 18px;"><strong>Constraints:</strong><br>1 ≤ arr.size() ≤ 10<sup>5</sup><br>1 ≤ marks ≤ 10<sup>6</sup></span></p></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>STL</code>&nbsp;
